# 录音规范

音色克隆的上限在录音这一步就定了，后面怎么调参都补不回来。按这份做，10 分钟素材就够用。

## 环境

- 房间越静越好：关空调、风扇、窗户、冰箱门
- **不要**有背景音乐、别人的说话声、电视声
- 手机自带录音或 Mac 语音备忘录都行，不用专业设备
- 房间别太空（有回声），衣柜前、床边、挂窗帘的地方都比空房间好

## 位置

- 嘴到麦克风 **15-20 厘米**，正对着说
- 不要贴太近（会喷麦、气流声）
- 不要用耳机麦克风（底噪大、声音发闷）

## 说什么

- 3-10 秒一条，一共 40 条左右
- 用**你平时说话的语速和音量**，不要播音腔、不要念课文的感觉
- 要包含你常用的语气词：「啊」「就」「那个」「行吧」「我跟你讲」
- 内容分几类覆盖情绪：日常陈述、吐槽、疑问、兴奋、长句叙述、短语气词
- 不要唱歌、喊、耳语

脚本参考：`docs/scripts/录音脚本.txt`

## 格式

- WAV 或 M4A，单声道
- 一条一个文件，命名 `001.m4a`、`002.m4a`
- 一整段录完也可以，但每条之间停 1 秒以上

## 录完自检

- 戴耳机听一遍：有电流声、回声、空调声 → 重录
- 有没有削波（波形顶到边）→ 离麦远一点重录
- 有没有念错、卡壳、清嗓子 → 单独重录那一条
- 总时长：**少于 3 分钟效果会很差**，10 分钟以上明显更好

## 常见错误

| 问题 | 后果 |
|---|---|
| 用耳机麦录 | 声音发闷，克隆出来也闷 |
| 房间太空 | 有回声，模型学到「在桶里说话」的感觉 |
| 念新闻稿 | 克隆出的声音念别的句子会很怪 |
| 只有一种情绪 | 说高兴的话也像在念稿 |
| 背景有音乐 | 模型会把音乐当音色特征学进去 |
